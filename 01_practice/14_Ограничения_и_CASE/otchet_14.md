# Отчёт по практической работе № 14

**Тема:** Ограничения и условные выражения в SQL

**Цель работы:** Изучить применение ограничений целостности и функций SQL для обработки и проверки данных.

В ходе практической работы были рассмотрены ограничения `CHECK`, `UNIQUE` и `DEFAULT`. Для проверки этих ограничений использовались отдельные тестовые таблицы, чтобы не изменять существующие данные основной таблицы `product`.

С помощью выражения `CASE` были сформированы категории товаров по стоимости: «дёшево», «средне» и «дорого». Функция `COALESCE` использовалась для замены значений `NULL` заданным значением, а `NULLIF` — для предотвращения деления на ноль. Также был рассмотрен порядок сортировки товаров с помощью `CASE` внутри `ORDER BY`.

В одном из заданий был исправлен запрос с выражением `CASE`: для завершения конструкции необходимо использовать ключевое слово `END`. Отдельно был проверен результат работы `COALESCE(NULL, NULL, 5)`, который возвращает значение `5`, поскольку это первое значение, отличное от `NULL`.

В заключительном задании была рассмотрена конструкция `UPDATE` с `CASE`, позволяющая заменить отрицательные цены нулём. Для проверки использовалась тестовая таблица, чтобы избежать непреднамеренного изменения данных в основной таблице.

**Вывод:** В ходе работы были изучены ограничения целостности и условные выражения SQL. `CHECK` позволяет контролировать допустимые значения, `UNIQUE` запрещает повторения, а `DEFAULT` задаёт значение по умолчанию. `CASE`, `COALESCE` и `NULLIF` помогают обрабатывать данные и формировать результаты запросов с учётом заданных условий.
