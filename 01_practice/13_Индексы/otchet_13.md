# Отчёт по практической работе № 13

**Тема:** Индексы в базе данных

**Цель работы:** Изучить создание, удаление и использование индексов в SQL.

В ходе практической работы были изучены способы создания индексов для таблицы `product`. Были рассмотрены индексы для столбцов `price`, `title` и `category_id`, а также составные индексы.

Для проверки использования индексов применялась команда `EXPLAIN QUERY PLAN`, позволяющая просматривать план выполнения запросов. Также было изучено удаление индексов с помощью команды `DROP INDEX` и сравнение выполнения запросов с индексом и без него.

При создании уникального индекса для столбца `title` возникла ошибка `UNIQUE constraint failed: product.title`. Она означает, что в таблице есть повторяющиеся названия товаров, поэтому создать уникальный индекс не удалось.

Дополнительно было рассмотрено создание индекса по выражению `LOWER(title)`. Также было установлено, что для первичного ключа обычно не требуется создавать отдельный индекс, поскольку база данных индексирует его автоматически.

**Вывод:** В ходе работы были изучены основные операции с индексами. Индексы могут ускорять поиск данных, но уникальный индекс нельзя создать, если в столбце имеются повторяющиеся значения.
