# Отчёт по практической работе № 11
**Тема: Соединение таблиц JOIN**

В ходе практической работы были изучены способы соединения таблиц в SQL. Были рассмотрены операторы `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN` и `FULL JOIN`, а также использование псевдонимов таблиц и условия соединения `ON`.

Были составлены запросы для вывода товаров вместе с названиями категорий, поиска товаров без категории и категорий без товаров. Также были выполнены запросы для подсчёта количества товаров в каждой категории, фильтрации категорий по названию и соединения нескольких таблиц.

Дополнительно были рассмотрены соединение таблицы с самой собой (`SELF JOIN`), поиск ошибки в запросе без условия `ON`, предсказание результата `LEFT JOIN` и переписывание `RIGHT JOIN` через `LEFT JOIN`.

В результате практической работы были закреплены навыки соединения данных из нескольких таблиц с помощью SQL. Поставленные задачи выполнены.
