# Отчёт по практической работе № 6

## Изменение структуры таблиц в SQLite

**Цель работы:** изучить способы изменения структуры таблиц в SQLite, научиться добавлять, удалять и переименовывать столбцы, изменять названия таблиц и выполнять их пересоздание с сохранением данных.

В ходе работы были изучены основные команды SQL для изменения структуры базы данных. С помощью `ALTER TABLE` были добавлены и удалены столбцы, переименован столбец `name` в `title`, а таблица `category` переименована в `categories`.

Также была выполнена операция удаления таблицы `product` и её последующего создания. Был добавлен столбец `created` для хранения даты, а тип данных столбца `price` изменён с `TEXT` на `REAL` путём пересоздания таблицы и переноса данных.

Для ограничения значений цены было использовано условие `CHECK (price > 0)`, которое запрещает добавлять цены, не соответствующие заданному условию. При пересоздании таблицы данные переносились из старой таблицы в новую с помощью команды `INSERT INTO ... SELECT`.

В ходе работы было установлено, что SQLite не поддерживает прямое изменение типа столбца с помощью команды `ALTER COLUMN`. Для этого необходимо создать новую таблицу, перенести данные, удалить старую таблицу и переименовать новую.

Также было проверено, что добавление нового столбца не изменяет количество записей в таблице.

**Вывод:** в ходе практической работы были изучены основные способы изменения структуры таблиц SQLite. Получены навыки добавления, удаления и переименования столбцов, изменения ограничений и типов данных, а также пересоздания таблиц с переносом существующих данных.
