# Отчёт по практической работе № 9
## Тема: Выборка данных SELECT

Цель работы — научиться выбирать данные из таблицы с помощью команды `SELECT`, фильтровать записи, сортировать результаты и ограничивать количество выводимых строк.

В ходе работы были выполнены запросы к таблице `product`, содержащей поля `title`, `price` и `category_id`. С помощью условия `WHERE` были выбраны товары по цене, названию и наличию категории. Для поиска использовались операторы `BETWEEN`, `LIKE`, а также проверка `IS NULL`.

Для сортировки товаров применялась команда `ORDER BY` с параметром `DESC`, позволяющим выводить товары от самой высокой цены к самой низкой. Команда `LIMIT` использовалась для ограничения количества записей. Также был выполнен запрос для поиска товаров, цена которых выше средней, с исключением товаров без категории.

При выполнении задания с логическими операторами было рассмотрено, что `AND` имеет более высокий приоритет, чем `OR`. Для изменения порядка вычисления условий используются скобки. В последнем задании был выполнен запрос, который выбирает товары, названия которых начинаются на букву «М», сортирует их по цене по возрастанию и выводит первые две записи.

В ходе работы выяснилось, что в таблице поле с названием товара называется `title`, а не `name`, поэтому запросы были скорректированы под фактическую структуру базы данных.

**Вывод:** в результате практической работы изучены основные способы выборки данных в SQLite: фильтрация с помощью `WHERE`, поиск по шаблону через `LIKE`, работа с `NULL`, сортировка через `ORDER BY` и ограничение результатов с помощью `LIMIT`. Полученные навыки позволяют получать из таблицы только необходимые данные.
